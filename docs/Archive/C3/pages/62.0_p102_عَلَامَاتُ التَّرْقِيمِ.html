تَعْرِيفُ عَلَامَاتِ التَّرْقِيمِ

هِيَ إِشَارَاتُ مُرُورٍ تُوضَعُ بَيْنَ الْجُمَلِ لِتُنَظِّمَ السَّيْرَ، فَتُخْبِرُ الْقَارِئَ مَتَى يَقِفُ، وَمَتَى يَتَعَجَّبُ، وَمَتَى يَسْأَلُ، لِيُفْهَمَ الْمَعْنَى صَحِيحاً بِدُونِ اخْتِلَاطٍ.

جَدْوَلُ مُلَخَّصِ عَلَامَاتِ التَّرْقِيمِ وَاسْتِخْدَامَاتِهَا
الرَّمْزُ الاسْمُ الاسْتِخْدَامُ (مَتَى نَضَعُهَا؟)
( . ) النُّقْطَةُ عِنْدَ انْتِهَاءِ الْكَلَامِ، وَاكْتِمَالِ الْمَعْنَى تَمَاماً، وَنِهَايَةِ الْفِقْرَةِ.
( : ) النُّقْطَتَانِ بَعْدَ الْقَوْلِ (قَالَ، أَجَابَ، رَدَّ). وَقَبْلَ التَّعْدَادِ وَالتَّفْصِيلِ (فُصُولُ السَّنَةِ أَرْبَعَةٌ: الرَّبِيعُ، وَالصَّيْفُ، وَالْخَرِيفُ، وَالشِّتَاءُ).
( ... ) النِّقَاطُ المُتَعَدِّدَةُ (عَادَةً ٣ نِقَاطٍ) لِلدَّلَالَةِ عَلَى كَلَامٍ مَحْذُوفٍ أَوْ بَقِيَّةٍ لَمْ نُكْمِلْهَا.
( ، ) الفَاصِلَةُ فَاصِلٌ قَصِيرٌ لِأَخْذِ نَفَسٍ، نَضَعُهَا بَيْنَ الْجُمَلِ الْقَصِيرَةِ، وَقَبْلَ حُرُوفِ الْعَطْفِ (وَ، فـ)، وَبَعْدَ النِّدَاءِ (يَا بُنَيَّ، اصْبِرْ).
( ؛ ) الفَاصِلَةُ المَنْقُوطَةُ (القَاطِعَةُ) تَدُلُّ عَلَى وَقْفٍ مُتَوَسِّطٍ، وَتَقَعُ بَيْنَ جُمَلٍ بَسِيطَةٍ تَامَّةِ الْمَعْنَى لِتُكَوِّنَ جُمْلَةً مُرَكَّبَةً. وَكَذَلِكَ تُوضَعُ بَيْنَ جُمْلَتَيْنِ، الثَّانِيَةُ سَبَبٌ لِلْأُولَى (نَجَحَ الطَّالِبُ؛ لِأَنَّهُ سَهِرَ اللَّيَالِيَ).
( ! ) عَلَامَةُ التَّعَجُّبِ لِإِظْهَارِ الدَّهْشَةِ، الْفَرَحِ، الْحُزْنِ، أَوْ الِاسْتِغْرَابِ (مَا أَجْمَلَ السَّمَاءَ! ، وَاحَسْرَتَاهُ!).
( ؟ ) عَلَامَةُ الِاسْتِفْهَامِ بَعْدَ السُّؤَالِ دَائِماً (مَا اسْمُكَ؟ ، هَلْ ذَاكَرْتَ؟).
( « » ) عَلَامَةُ التَّنْصِيصِ (الْمُزْدَوَجَانِ) لِحَصْرِ كَلَامٍ مَنْقُولٍ بِالْحَرْفِ (كَمَا هُوَ دُونَ تَغْيِيرٍ) مِثْلَ الْأَقْوَالِ الْمَأْثُورَةِ أَوْ كَلَامِ الْعُلَمَاءِ. قَالَ الْحَكِيمُ: «الْوَقْتُ ثَمِينٌ».
( ( ) ) الْقَوْسَانِ تُسْتَخْدَمَانِ لِحَصْرِ الْكَلِمَاتِ الْمَشْرُوحَةِ أَوِ الْعِبَارَاتِ الَّتِي يُرَادُ أَنْ يُلْفَتَ النَّظَرُ إِلَيْهَا.
( - - ) الشَّرْطَتَانِ / الِاعْتِرَاضِ لِحَصْرِ جُمْلَةٍ اعْتِرَاضِيَّةٍ (لَوْ حَذَفْنَاهَا لَا يَتَغَيَّرُ الْمَعْنَى)، كَالدُّعَاءِ وَالتَّوْضِيحِ. (أَخِي - سَلَّمَهُ الزَّمَانُ - مُخْلِصٌ).
أَوْلاً: عَلَامَاتُ الْوَقْفِ وَالْفَصْلِ
  • • النُّقْطَةُ ( . ) : عِنْدَ انْتِهَاءِ الْكَلَامِ، وَاكْتِمَالِ الْمَعْنَى تَمَاماً، وَنِهَايَةِ الْفِقْرَةِ.
  • • الفَاصِلَةُ ( ، ) : فَاصِلٌ قَصِيرٌ لِأَخْذِ نَفَسٍ، نَضَعُهَا بَيْنَ الْجُمَلِ الْقَصِيرَةِ، وَقَبْلَ حُرُوفِ الْعَطْفِ (وَ، فـ)، وَبَعْدَ النِّدَاءِ (يَا بُنَيَّ، اصْبِرْ).
  • • الفَاصِلَةُ المَنْقُوطَةُ ( ؛ ) : تُوضَعُ بَيْنَ جُمْلَتَيْنِ، الثَّانِيَةُ سَبَبٌ لِلْأُولَى (نَجَحَ الطَّالِبُ؛ لِأَنَّهُ سَهِرَ اللَّيَالِيَ).
ثَانِياً: عَلَامَاتُ الِانْفِعَالِ وَالِاسْتِفْمُهِمِّ
  • • عَلَامَةُ التَّعَجُّبِ ( ! ) : لِإِظْهَارِ الدَّهْشَةِ، الْفَرَحِ، الْحُزْنِ، أَوْ الِاسْتِغْرَابِ (مَا أَجْمَلَ السَّمَاءَ! ، وَاحَسْرَتَاهُ!).
  • • عَلَامَةُ الاسْتِفْمُهِمِّ ( ؟ ) : بَعْدَ السُّؤَالِ دَائِماً (مَا اسْمُكَ؟ ، هَلْ ذَاكَرْتَ؟).
ثَالِثاً: عَلَامَاتُ التَّوْضِيحِ وَالنَّقْلِ
  • • النُّقْطَتَانِ ( : ) : بَعْدَ الْقَوْلِ (قَالَ، أَجَابَ، رَدَّ). وَقَبْلَ التَّعْدَادِ وَالتَّفْصِيلِ (فُصُولُ السَّنَةِ أَرْبَعَةٌ: الرَّبِيعُ، وَالصَّيْفُ، وَالْخَرِيفُ، وَالشِّتَاءُ).
  • • النِّقَاطُ المُتَعَدِّدَةُ ( ... ) : (عَادَةً ٣ نِقَاطٍ) لِلدَّلَالَةِ عَلَى كَلَامٍ مَحْذُوفٍ أَوْ بَقِيَّةٍ لَمْ نُكْمِلْهَا.
  • • عَلَامَةُ التَّنْصِيصِ ( « » ) : لِحَصْرِ كَلَامٍ مَنْقُولٍ بِالْحَرْفِ (كَمَا هُوَ دُونَ تَغْيِيرٍ) مِثْلَ الْأَقْوَالِ الْمَأْثُورَةِ أَوْ كَلَامِ الْعُلَمَاءِ. قَالَ الْحَكِيمُ: «الْوَقْتُ ثَمِينٌ».
  • • الشَّرْطَتَانِ / الِاعْتِرَاضِ ( - - ) : لِحَصْرِ جُمْلَةٍ اعْتِرَاضِيَّةٍ (لَوْ حَذَفْنَاهَا لَا يَتَغَيَّرُ الْمَعْنَى)، كَالدُّعَاءِ وَالتَّوْضِيحِ. (أَخِي - سَلَّمَهُ الزَّمَانُ - مُخْلِصٌ).
⚠️ تَنْبِيهٌ: يَجِبُ الِانْتِبَاهُ إِلَى عَلَامَاتِ التَّرْقِيمِ؛ لِأَنَّهَا تُوضَحُ مَعْنَى الْكَلَامِ بِدُونِ اخْتِلَاطٍ كَمَا فِي الْجُمَلِ الِاعْتِرَاضِيَّةِ أَوِ التَّعَجُّبِ.
فَائِدَةٌ: عَلَامَاتُ التَّرْقِيمِ فِي اللُّغَةِ الْعَرَبِيَّةِ لَيْسَتْ مُجَرَّدَ زِينَةٍ، بَلْ هِيَ جُزْءٌ أَسَاسِيٌّ لِفَهْمِ النَّصِّ وَاسْتِيعَابِ الْمَعْنَى بِدِقَّةٍ؛ لِأَنَّهَا تُعَوِّضُ عَنِ النَّبْرَاتِ الصَّوْتِيَّةِ الْمَوْجُودَةِ فِي الْكَلَامِ الْمَنْطُوقِ.
