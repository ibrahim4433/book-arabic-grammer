\# Method: sessions.create



\- \[HTTP request](https://developers.google.com/jules/api/reference/rest/v1alpha/sessions/create#body.HTTP\_TEMPLATE)

\- \[Request body](https://developers.google.com/jules/api/reference/rest/v1alpha/sessions/create#body.request\_body)

\- \[Response body](https://developers.google.com/jules/api/reference/rest/v1alpha/sessions/create#body.response\_body)



Creates a new session.



\### HTTP request



`POST https://jules.googleapis.com/v1alpha/sessions`



The URL uses \[gRPC Transcoding](https://google.aip.dev/127) syntax.



\### Request body



The request body contains an instance of `https://developers.google.com/jules/api/reference/rest/v1alpha/sessions#Session`.



\### Response body



If successful, the response body contains a newly created instance of `https://developers.google.com/jules/api/reference/rest/v1alpha/sessions#Session`.
