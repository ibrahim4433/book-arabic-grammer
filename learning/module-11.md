# Module 11: The Compiler (`build.py`)

## 1. Tool Definition
**What is it?** 
Before you can read a book, the loose pages must be bound together at the printing press. 
The `build.py` script is the printing press of this repository. It takes hundreds of loose, individual HTML files generated by the AI in the `pages/` directory, extracts their contents, wraps them in a master layout, and uses the `WeasyPrint` rendering engine to mathematically compile them into a single, highly polished A4 PDF file (`output/export/book.pdf`).

## 2. I/O Mapping
*   **Inputs:** 
    *   Hundreds of physical HTML files (`pages/*.html`).
    *   The Front and Back cover images (`pages/cover/front-cover.jpg`).
    *   The Global Stylesheet (`styles/main.css`).
*   **Processes:**
    *   Sorts all pages alphabetically.
    *   Uses Regex to surgically extract the `<body>` content of every individual HTML file, discarding their `<head>` tags to prevent CSS collisions.
    *   Wraps all 200 extracted bodies into a massive `_master_html` template.
    *   Passes the massive HTML string to `WeasyPrint` for headless PDF rendering.
*   **Outputs:**
    *   `output/export/book.pdf` (The final, compiled textbook).
    *   A `BuildResult` dataclass tracking processing time and any I/O errors.

#### Line-by-Line Commentary
*   **Line 24:** `@dataclass(frozen=True)`

### Block B: The HTML Extractors & Wrappers
If we merge 200 HTML files, we can't have 200 `<!DOCTYPE html>` tags in the same document. We must extract only the inner content.

```python
# From build.py

59: def _extract_body(content: str, filepath: Path) -> str:
60:     """Extract inner body content from an HTML file string."""
61:     body_match = re.search(r"<body[^>]*>(.*?)</body>", content, re.DOTALL | re.IGNORECASE)
62:     if body_match:
63:         return body_match.group(1)
64:     print(f"  → Info: No <body> tag in {filepath}. Using full content as fragment.")
65:     return content
66: 
67: 
68: def _build_cover_html(image_path: Path, *, break_after: str = "page") -> str:
69:     return f"""
70:     <div class="cover-page-wrapper" style="break-after: {break_after};">
71:         <img src="{image_path.as_posix()}" alt="Cover">
72:     </div>
73:     """
74: 
75: 
76: def _master_html(body_content: str, stylesheet: Path, watermark_text: str) -> str:
77:     """Wrap accumulated body content in the full master HTML template."""
78:     return f"""<!DOCTYPE html>
79: <html lang="ar" dir="rtl">
80: <head>
81:     <meta charset="UTF-8">
82:     <title>Book Compilation</title>
83:     <link rel="stylesheet" href="{stylesheet.as_posix()}">
84:     <style>
85:         @page cover {{
86:             margin: 0;
87:             size: A4;
88:             @bottom-center {{ content: none; }}
89:         }}
90:         .cover-page-wrapper {{
91:             page: cover;
92:             width: 210mm;
93:             height: 297mm;
94:             overflow: hidden;
...
107: <body>
108:     <!-- Global Fixed Background -->
109:     <div class="global-background-layer"></div>
110: 
111:     <!-- Global Fixed Watermark -->
112:     <div class="global-watermark-layer">
113:         <span class="watermark-text">{watermark_text}</span>
114:     </div>
115: 
116:     <!-- Content Pages -->
117:     {body_content}
118: </body>
119: </html>
120: """
```
#### Line-by-Line Commentary
*   **Line 61:** `re.search(r"<body[^>]*>(.*?)</body>", content, re.DOTALL | re.IGNORECASE)`
    *   This Regex is the core of the extraction. It hunts for the exact starting `<body>` tag, captures all content (`(.*?)`), and stops at `</body>`. `re.DOTALL` is critical because it forces the regex to read across multiple lines.
*   **Lines 68-73:** `_build_cover_html` programmatically generates a physical CSS page just for the JPG covers. It forces a `break-after: page;` so the cover doesn't leak onto the first grammar lesson.
*   **Line 85:** `@page cover { ... size: A4; }`
    *   This is standard Paged Media CSS. It tells WeasyPrint that the wrapper should map to physical A4 paper dimensions.
*   **Line 117:** `{body_content}`
    *   This single python f-string variable will eventually hold all 200 extracted pages of the book, dumping them right in the center of the master wrapper.

### Block C: Dependency Validation & File Collection
Before the system begins heavy processing, it checks if it actually has the files and libraries it needs.

```python
# From build.py

126: def collect_pages(config: BuildConfig) -> list[Path]:
127:     """Return sorted list of page HTML files, excluding TEMPLATE_ files."""
128:     all_files = sorted(config.pages_dir.glob("*.html"))

133:     """Main build pipeline. Returns a BuildResult."""
134:     result = BuildResult()

136: 
137:     # ── Validate WeasyPrint import ─────────────────────────────────────────
138:     try:

140:     except ImportError as exc:
141:         raise BuildError(
142:             "WeasyPrint is not installed.\nRun: pip install -r requirements.txt"
143:         ) from exc
144:     except OSError as exc:
145:         raise BuildError(
146:             "WeasyPrint is installed, but its native GTK/Pango libraries are missing.\n"
147:             "See: https://doc.courtbouillon.org/weasyprint/stable/first_steps.html"
148:         ) from exc
149: 
150:     # ── Collect pages ──────────────────────────────────────────────────────
151:     pages = collect_pages(config)
152:     if not pages:

```
#### Line-by-Line Commentary
*   **Lines 128-129:** `sorted(config.pages_dir.glob("*.html"))`
    *   It grabs every HTML file and relies on Python's alphabetical sort. Because the AI generates files named `01.0...`, `02.0...`, the alphabetical sort perfectly mimics the physical page order. It explicitly excludes `TEMPLATE_` snippet files.
*   **Lines 138-148:** The `try...except` block for `weasyprint`. 
    *   WeasyPrint requires heavy C++ libraries (GTK/Pango) to physically draw fonts. If they are missing from the OS, it throws an `OSError`. This block gracefully catches it and provides a link to the installation docs instead of crashing with a confusing stack trace.
*   **Lines 151-155:** It triggers `collect_pages`. If the `pages/` directory is empty, it raises a fatal error and stops the build immediately.

#### Line-by-Line Commentary

*   **Line 199:** `config.output_pdf.parent.mkdir(parents=True, exist_ok=True)`

*   **Line 202:** `HTML(string=full_html, base_url=".").write_pdf(str(config.output_pdf))`
    *   *The Engine*. WeasyPrint takes the massive HTML string in memory, parses the CSS, calculates physical A4 layouts, embeds the Arabic fonts, and saves the binary PDF file to the hard drive. `base_url="."` is required so it knows where to find local images!
