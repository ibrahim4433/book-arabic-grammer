كَيْف تُعْرِبُ ؟( خَطْوَاتِ الْإِعْرَابِ الصَّحِيحِ (تتمة)

أ. الياس خفيف
994066850 963+
( فِي ) - حَرْفَ جَرِّ مَبْنِيِّ
( النُّجَّاحِ ) - اِسْمَ مَجْرُورَ ب ( فِي ) وَعُلَّامَةَ جُرِّهِ الْكُسَّرَةِ
( و ) - حَرْفَ عَطْفٍ
( التَّفَوُّقِ ) - اِسْمَ مَعْطُوفٍ عَلَى ( النُّجَّاحَ ) مَجْرُورٌ وَعُلَّامَةُ جُرِّهِ الْكُسَّرَةِ .( لأَنّ الْمَعْطُوفِ يَتْبَعُ الْمَعْطُوفُ عَلَيْهِ ).
تَدْرِيبَاتٍ وَتَطْبِيقَاتٍ عَمَلِيَّةٍ ( مُسْتَخْرَجَةً مِن الدَّرْسِ )

السُّؤَالَ الْأَوَّلَ اِمْلَأْ الْفَرَاغَاتِ لِاِكْتِشَافَ الْمَوْقِعِ الْإِعْرَابِيِّ فِي الْجُمْلَةِ الْفِعْلِيَّةِ :

١ لِمَعْرِفَةُ الْفَاعِلِ نَسْأَلُ بِكَلِمَةٍ :.....................

٢ لِمَعْرِفَةُ الْمَفْعُولِ بِه نَسْأَلُ بِكَلِمَةٍ :.....................

٣ لِمَعْرِفَةُ الْمَفْعُولِ لِأَجَّلَهُ ( السَّبَبَ ) نَسْأَلُ بِكَلِمَةٍ :.....................

٤ لِمَعْرِفَةُ الْحَالِ ( الْهَيْئَةَ ) نَسْأَلُ بِكَلِمَةٍ :.....................

٥ لِمَعْرِفَةُ ظَرْفِ الزَّمَانِ نَسْأَلُ بِكَلِمَةٍ :.....................

السُّؤَالَ الثَّانِي أَعْرَبَ الْكَلِمَاتُ الْمُلَوَّنَةُ بَنَّاءً عَلَى الْخَطْوَاتِ الْأَرْبَعَ :

شَرِبَ الْمَرِيضُ الدَّوَاءَ أَمَلًا فِي الشِّفَاءِ

١ الْمَرِيضُ :

٢ الدَّوَاءُ :

٣ أَمَلًا :

السُّؤَالَ الثَّالِثُ اِسْتَخْرَجَ مِنَ الْجُمْلَةِ التَّالِيَةِ الْفَاعِلَ وَالْمَفْعُولَ بِهِ ثُمَّ أَعْرِبْهُمَا :

يَقْرَأُ الطَّالِبُ الْقِصَّةَ بِشَغَفٍ

١ الْفَاعِلُ :

٢ الْمَفْعُولُ بِهِ :

السُّؤَالَ الرَّابِعُ أَعْرَبَ الْكَلِمَاتُ الْمُلَوَّنَةُ بَنَّاءً عَلَى الْخَطْوَاتِ الْأَرْبَعَ :

يُحِبُّ اللَّهُ الْمُحْسِنِينَ

١ اللَّهُ :

٢ الْمُحْسِنِينَ :

⚠️ نَصِيحَةٌ ذَهَبِيَّةٌ:

فِي الْإِعْرَابِ ، دَائِمًا اِبْدَأْ بِمَعْرِفَةِ نَوْعِ الْجُمْلَةِ ( اِسْمِيَّةً أَو فِعْلِيَّةً )، ثُمَّ اِبْحَثْ عَنِ الرُّكْنَيْنِ الْأَسَاسِيَّيْنِ ( الْمُبْتَدَأُ وَالْخَبَرُ ، أَو الْفِعْلُ وَالْفَاعِلُ ) قَبْلَ الْبَحْثِ عَنِ الْمُكَمِّلَاتِ كَالْمَفَاعِيلِ .
