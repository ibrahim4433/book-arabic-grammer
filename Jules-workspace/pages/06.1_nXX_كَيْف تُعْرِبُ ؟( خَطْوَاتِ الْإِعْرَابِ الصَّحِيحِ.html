التَّطْبِيقَ الْعَمَلِيَّ الشَّامِلَ ( 2 )

ذَاكَرَ الطَّالِبُ الْمُجْتَهِدُ الدُّرُوسَ صَبَاحًا مُرَكَّزًا رَغْبَةً فِي النُّجَّاحِ وَالتَّفَوُّقِ .

فِي بِدَايَةِ الْإِعْرَابِ ، نَسْأَلُ دَائِمًا : مَا نَوْعِ الْجُمْلَةِ ؟ بَدَأَتْ بِفِعْلِ ( ذَاكِرَ )، إِذَن هِي جُمْلَةِ فِعْلِيَّةِ نَبْدَأُ بِفَكِّ شَفْرَاتِهَا بِطَرْحِ الْأسْئِلَةِ

الْكَلِمَةُ السُّؤَالُ الْإِعْرَابُ
( ذَاكِرَ ) - فعَلّ مَاضٍ مَبْنِيِّ عَلَى الْفَتْحِ .( الْفِعْلِ الْمَاضِي دَائِمًا مَبْنِيَّ ).
( الطَّالِبُ ) مَنَّ ذَاكِرَ ؟( الْإِجَابَةَ عَن " مَنَّ " تُعْطِينَا الْفَاعِلُ ) فَاعِلَ مَرْفُوعَ وَعُلَّامَةَ رَفْعِهِ الضَّمَّةَ
( الْمُجْتَهِدُ ) الطَّالِبَ مَنَّ ؟/ مَا صَفَّتِهِ ؟ نَعَتْ ( أَو صَفَّةُ ) مَرْفُوعٌ وَعُلَّامَةُ رَفْعِهِ الضَّمَّةَ .( تَتْبَعُ الْمَوْصُوفُ ).
( الدُّرُوسَ ) مَاذَا ذَاكِرُ ؟( الْإِجَابَةَ عَن " مَاذَا " تُعْطِينَا الْمَفْعُولُ بِه ) مَفْعُولٌ بِه مَنْصُوبٍ وَعُلَّامَةِ نُصْبِهِ الْفَتَحَةِ
( صَبَاحًا ) مَتَى ذَاكِرُ ؟( الْإِجَابَةَ عَن " مَتَى " تُعْطِينَا ظَرْفُ الزَّمَانِ / الْمَفْعُولَ فِيهِ ) ظَرُفَ زَمَانُ مَنْصُوبٍ وَعُلَّامَةِ نُصْبِهِ الْفَتَحَةِ
( مَرْكَزًا ) كَيْف ذَاكِرُ ؟( الْإِجَابَةَ عَن " كَيْف " تُعْطِينَا الْحَالُ ) حَالَ مَنْصُوبَةَ وَعُلَّامَةَ نُصْبِهَا الْفَتَحَةِ .( الْحَالُ دَائِمًا مَنْصُوبَةً ).
( رَغْبَةً ) لِمَاذَا ذَاكِرَ ؟( مِن أَجَل مَاذَا ؟)( الْإِجَابَةَ عَن " لِمَاذَا " تُعْطِينَا الْمَفْعُولُ لِأَجَّلَهُ ) مَفْعُولٌ لِأَجَّلَهُ مَنْصُوبٌ وَعُلَّامَةُ نُصْبِهِ الْفَتَحَةِ
( فِي ) - حَرْفَ جَرِّ مَبْنِيِّ
( النُّجَّاحِ ) - اِسْمَ مَجْرُورَ ب ( فِي ) وَعُلَّامَةَ جُرِّهِ الْكُسَّرَةِ
( و ) - حَرْفَ عَطْفٍ
( التَّفَوُّقِ ) - اِسْمَ مَعْطُوفٍ عَلَى ( النُّجَّاحَ ) مَجْرُورٌ وَعُلَّامَةُ جُرِّهِ الْكُسَّرَةِ .( لأَنّ الْمَعْطُوفِ يَتْبَعُ الْمَعْطُوفُ عَلَيْهِ ).
