# Blueprint: أسطر النص المتممة (Complementary Text Lines)

**GOAL**: Map the complementary verses or appended text lines accurately using standard poetry layouts or block containers.

### HTML STRUCTURE & TEMPLATES

If the text contains poetic verses, use **`TEMPLATE_C_POEM.html`**. If it contains standard prose, use **`TEMPLATE_C_BLOCK.html`**.

**1. Main Section Header:**
```html
<div class="content-block" id="bXXXXX">
    <div class="block-header">
        <h2>أسطر النص المتممة</h2>
    </div>
</div>
```

**2. For Poetic Verses (If applicable):**
```html
<!-- Inside TEMPLATE_C_POEM.html layout -->
<div class="poem-container mt-2mm" id="bXXXXX">
    <div class="poem-row">
        <div class="poem-right">... (الشطر الأول) ...</div>
        <div class="poem-left">... (الشطر الثاني) ...</div>
    </div>
</div>
```

**3. For Prose/Standard Text (If applicable):**
```html
<div class="content-block mt-2mm" id="bXXXXX">
    <div class="block-body p-2mm">
        <p class="m-0 text-sm">...</p>
    </div>
</div>
```

### RULES
- **Determine Layout Intelligently:** Use the poem layout if the text is structured as verses, otherwise use the standard block layout.
- **Never Summarize:** Include every single line from the raw text.
- **Unique IDs:** Ensure every `content-block` or `poem-container` has a unique `id="bXXXXX"`.
