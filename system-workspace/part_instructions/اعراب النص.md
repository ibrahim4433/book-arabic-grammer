# Blueprint: إعراب النص (Text Parsing/Grammar Detail)

**GOAL**: Map the detailed grammar parsing (إعراب) and linguistic breakdown of the verses into a structured HTML view.

### HTML STRUCTURE & TEMPLATES

Use **`TEMPLATE_C_BLOCK.html`** as your primary container for the parsing content. 
If the text contains a structured table-like breakdown (Word -> Parsing), use **`TEMPLATE_C_TABLE.html`**.

**1. Main Section Header:**
```html
<div class="content-block" id="bXXXXX">
    <div class="block-header">
        <h2>إعراب النص</h2>
    </div>
    <div class="block-body p-2mm">
        <!-- Insert the main introductory or paragraph-based parsing text here -->
        <p class="m-0 text-sm">...</p>
    </div>
</div>
```

**2. For Word-by-Word Parsing (if present in raw text):**
```html
<div class="content-block mt-2mm" id="bXXXXX">
    <div class="block-body p-0">
        <table class="data-table">
            <thead>
                <tr>
                    <th>الكلمة / الجملة</th>
                    <th>إعرابها</th>
                </tr>
            </thead>
            <tbody>
                <tr>
                    <td class="font-bold text-accent">...</td>
                    <td>...</td>
                </tr>
                <!-- Repeat for each parsed word/phrase -->
            </tbody>
        </table>
    </div>
</div>
```

### RULES
- **Never Summarize:** Include every single grammar rule and parsing detail from the raw text.
- **Diacritics (Harakat):** Grammar parsing requires 100% accurate diacritics. Restore any missing harakat carefully.
- **Unique IDs:** Ensure every `content-block` has a unique `id="bXXXXX"`.
