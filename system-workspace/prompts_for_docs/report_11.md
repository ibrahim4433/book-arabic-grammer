### `system-workspace/tools/new-tools/sync_pages.py`
- **Status:** Usable
- **Purpose:** Renames HTML files to match their physical page numbers as generated by WeasyPrint and generates Table of Contents (TOC) HTML files based on the updated numbering.
- **Inputs:** All lesson HTML files in `pages/`
- **Outputs:** Renamed HTML files in `pages/` and new TOC files (`pages/00.2_TOC.html`, `pages/00.3_TOC.html`).
- **Usage:** `python system-workspace/tools/new-tools/sync_pages.py`
- **Workflow Integration:** A crucial post-processing step to align file names with physical pagination and generate accurate TOCs before final PDF generation.
