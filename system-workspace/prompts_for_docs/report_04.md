### `system-workspace/tools/new-tools/fix_toc_styles.py`
- **Status:** Usable
- **Purpose:** Generates Table of Contents HTML pages (`00.X_TOC.html`) by scanning generated HTML files and extracting titles/numbers.
- **Inputs:** All HTML files in `pages/` (excluding templates).
- **Outputs:** Creates/overwrites `pages/00.X_TOC.html` files.
- **Usage:** `python3 system-workspace/tools/new-tools/fix_toc_styles.py`
- **Workflow Integration:** General generation workflow.
