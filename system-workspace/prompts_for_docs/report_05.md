### `system-workspace/tools/new-tools/debug_ocr.py`
- **Status:** Usable
- **Purpose:** A Gradio web UI tool for visually debugging OCR results with Tesseract, applying binarization and contrast adjustments.
- **Inputs:** User-uploaded images or PDFs (interactive).
- **Outputs:** Interactive Gradio UI (images and extracted text).
- **Usage:** `python3 system-workspace/tools/new-tools/debug_ocr.py`
- **Workflow Integration:** General utility for OCR debugging.
