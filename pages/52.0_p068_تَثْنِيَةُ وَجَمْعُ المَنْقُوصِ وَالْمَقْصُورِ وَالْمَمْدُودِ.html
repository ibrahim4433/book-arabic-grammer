المستوى التأسيسي
تَثْنِيَةُ وَجَمْعُ المَنْقُوصِ وَالْمَقْصُورِ وَالْمَمْدُودِ

تَثْنِيَةُ وَجَمْعُ المَنْقُوصِ وَالْمَقْصُورِ وَالْمَمْدُودِ

أ. حنا خفيف
١- الاسْمُ المَنْقُوصُ
  • • عِنْدَ التَّثْنِيَةِ: تُرَدُّ الياء المحذوفة (قَاضٍ -> قَاضِيَانِ، قَاضِيَيْنِ). الْبَانِي -> الْبَانِيَانِ.
  • • عِنْدَ جَمْعِ المُذَكَّرِ السَّالِمِ: تُحْذَفُ الياء دَائِماً (الرَّاعِي -> الرَّاعُونَ / الرَّاعِينَ). الْبَانِي -> الْبَانُونَ.
٢- الاسْمُ المَقْصُورُ
  • • عِنْدَ التَّثْنِيَةِ (إِذَا كَانَ ثُلَاثِيّاً): نُعِيدُ الألف لأصلها الواو أو الياء. (فَتَى -> فَتَيَانِ). (عَصَا -> عَصَوَانِ).
  • • عِنْدَ التَّثْنِيَةِ (إِذَا كَانَ فَوْقَ ٣ أَحْرُفٍ): تُقْلَبُ الألفُ ياءً دَائِماً. (مُسْتَشْفَى -> مُسْتَشْفَيَانِ). (مَبْنَى -> مَبْنَيَانِ).
⚠️ تَنْبِيهٌ مُهِمٌّ لِلْمَقْصُورِ: عِنْدَ جَمْعِ المُذَكَّرِ السَّالِمِ: تُحْذَفُ الألفُ دَائِماً وَيُفْتَحُ مَا قَبْلَهَا! (مُسْتَدْعَى -> مُسْتَدْعَوْنَ / مُسْتَدْعَيْنَ). (الْأَعْلَى -> الْأَعْلَوْنَ).
٣- الاسْمُ المَمْدُودُ
  • • إِذَا كَانَتِ الهَمْزَةُ أَصْلِيَّةً (مِنْ أَصْلِ الْفِعْلِ، قَرَأَ): تَبْقَى كَمَا هِيَ. (قَرَّاء -> قَرَّاءَانِ، قَرَّاؤُونَ).
  • • إِذَا كَانَتِ الهَمْزَةُ زَائِدَةً لِلتَّأْنِيثِ (لَا تُوجَدُ فِي الْفِعْلِ، حَسُنَ): تُقْلَب واوًا. (حَسْنَاء -> حَسْنَاوَانِ، حَسْنَاوَات). (صَحْرَاء -> صَحْرَاوَانِ).
  • • إِذَا كَانَتِ الهَمْزَةُ مُنْقَلِبَةً عَنْ أَصْلٍ (وَاو أَوْ يَاء، رَجَا): يَجُوزُ بَقَاؤُهَا أَوْ قَلْبُهَا وَاواً. (رَجَاء -> رَجَاءَانِ / رَجَاوَانِ). (سَمَاء -> سَمَاءَانِ / سَمَاوَانِ).
جَدْوَلُ مُقَارَنَةِ الْأَحْكَامِ (عِنْدَ التَّثْنِيَةِ وَالْجَمْعِ)
النَّوْعُ حُكْمُهُ عِنْدَ التَّثْنِيَةِ حُكْمُهُ عِنْدَ الْجَمْعِ السَّالِمِ
الْمَنْقُوصُ تُرَدُّ الياء المحذوفة تُحْذَفُ الياء دَائِماً
الْمَقْصُورُ الثُّلَاثِيُّ: نُعِيدُ الألف لأصلها / فَوْقَ الثُّلَاثِيِّ: تُقْلَبُ ياءً تُحْذَفُ الألفُ دَائِماً وَيُفْتَحُ مَا قَبْلَهَا
الْمَمْدُودُ الأَصْلِيَّةُ: تَبْقَى / لِلتَّأْنِيثِ: تُقْلَبُ واواً / مُنْقَلِبَةٌ: بَقَاؤُهَا أَوْ قَلْبُهَا الأَصْلِيَّةُ: تَبْقَى / لِلتَّأْنِيثِ: تُقْلَبُ واواً / مُنْقَلِبَةٌ: بَقَاؤُهَا أَوْ قَلْبُهَا
 
أَمْثِلَةٌ إِضَافِيَّةٌ لِلتَّطْبِيقِ
  • • رَأَيْتُ قَاضِيَيْنِ عَادِلَيْنِ. (مَنْقُوصٌ ثُنِّيَ بِإِبْقَاءِ الْيَاءِ).
  • • جَاءَ الرَّاعُونَ إِلَى الْحَقْلِ. (مَنْقُوصٌ جُمِعَ بِحَذْفِ الْيَاءِ).
  • • هَذَانِ فَتَيَانِ شُجَاعَانِ. (مَقْصُورٌ ثُلَاثِيٌّ رُدَّتْ أَلِفُهُ إِلَى أَصْلِهَا الْيَاءِ).
  • • زُرْتُ مُسْتَشْفَيَيْنِ. (مَقْصُورٌ فَوْقَ ثَلَاثِيٍّ قُلِبَتْ أَلِفُهُ يَاءً).
 
فَائِدَةٌ لُغَوِيَّةٌ مُهِمَّةٌ: فِي الِاسْمِ الْمَمْدُودِ الَّذِي هَمْزَتُهُ مُنْقَلِبَةٌ عَنْ أَصْلٍ، يَجُوزُ وَجْهَانِ، فَنَقُولُ فِي جَمْعِ "سَمَاءٍ": سَمَاءَاتٌ (بِإِبْقَاءِ الْهَمْزَةِ) وَ سَمَاوَاتٌ (بِقَلْبِهَا وَاواً)، وَكِلَاهُمَا صَحِيحٌ.
 
اخْتِبِرْ نَفْسَكَ

١ كَيْفَ يُثَنَّى الاسْمُ المَقْصُورُ إِذَا كَانَ ثُلَاثِيّاً وَإِذَا كَانَ فَوْقَ ثَلَاثَةِ أَحْرُفٍ؟

٢ مَاذَا يَحْدُثُ لِلِاسْمِ المَنْقُوصِ وَالمَقْصُورِ عِنْدَ جَمْعِهِمَا جَمْعَ مُذَكَّرٍ سَالِماً؟

٣ مَا هُوَ حُكْمُ هَمْزَةِ المَمْدُودِ إِذَا كَانَتْ زَائِدَةً لِلتَّأْنِيثِ عِنْدَ التَّثْنِيَةِ؟ هَاتِ مِثَالاً.
