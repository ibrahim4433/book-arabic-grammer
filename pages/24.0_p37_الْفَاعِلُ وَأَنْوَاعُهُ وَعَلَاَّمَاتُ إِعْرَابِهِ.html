مُقَدَّمَةٌ وَتَعْرِيفُ الْفَاعِلِ

تُحْدِثُنَا عَن الْجُمْلَةِ الْفِعْلِيَّةِ ، وَقُلْنَا إِنّهَا تَتُكُّونَ مِن رُكْنَيْنِ أَسَاسِيَّيْنِ الْفِعْلُ وَالْفَاعِلُ لكُلّ فعَلّ فَاعِلٍ لَا بَدَّ مِنهُ فَمَنٌّ هُو الْفَاعِلِ ؟ وكَيْف نُحَدِّدُ مَكَانَهُ بِدِقَّةٍ فِي الْجُمْلَةِ ؟

التَّعْرِيفَ : هُو مَن قَام بِالْفِعْلِ ، أَو اِتَّصَفَ بِه ( يَأْتِي بَعْد فعَلّ مَبْنِيٍّ لِلْمَعْلُومَ ).

  • • قَام بِالْفِعْلِ : مِثْل ( تَلْعَبُ الطِّفْلَةُ ). مَنِّ الَّتِي قَامَتْ بِاللُّعَبِ ؟ الطِّفْلَةَ إِذَن هِي الْفَاعِلِ
  • • اِتَّصَفَ بِالْفِعْلِ : مِثْل ( اِنْكَسَرَ الْغُصْنُ ) أَو ( مَاتَ الْعَصْفُورُ ). الْغُصْنَ لَم يَكْسِرُ نَفْسهُ ، بَل نَحْن أَلَحِقَنَا بِه صِفَةِ الْكَسْرِ وَالْعَصْفُورُ لَم يمُت نَفْسهُ ، بَل اِتَّصَفَ بِالْمَوْتِ إِذَن ( الْغُصْنَ ، الْعَصْفُورَ ) فَاعِلٌ
تَلْميحٌ - كَيْف تَكْتَشِفُ الْفَاعِلُ فِي الْجُمْلَةِ ؟: قِفْ قَبْل الْفِعْلِ وَاِسْأَلْ : ( مَنْ ؟ ). الْإِجَابَةَ هِي الْفَاعِلِ. مِثَالَ : شَرِبَ الدَّوَاءَ الْمَرِيضُ . ( مَنُّ شَرِبَ ؟ الْمَرِيضَ ). إِذَن ( الْمَرِيضَ ) هُو الْفَاعِلِ ، بُغْضَ النَّظَرِ عَن تَأَخُّرِهِ فِي الْجُمْلَةِ
قَاعِدَةَ ذَهَبِيَّةَ : الْفَاعِلُ دَائِمًا ( مَرْفُوعَ ). وَتَخْتَلِفُ عُلَّامَتُهُ حَسْب نَوْعِ الْاِسْمِ
الْعَلَامَةُ نَوْعُ الْاِسْمِ الْمِثَالُ
الضَّمَّةُ ( أَصِلِيَّةَ ) لِلْمُفْرَدَ حَفِظَ الطَّالِبُ الْقَصِيدَةَ
الضَّمَّةُ ( أَصِلِيَّةَ ) لِجَمَعَ التَّكْسيرُ حَفِظَ الطُّلَاَّبُ الْقَصِيدَةَ
الضَّمَّةُ ( أَصِلِيَّةَ ) لِجَمَعَ الْمُؤَنَّثُ السَّالِمُ تَحْفَظُ الطَّالِبَاتُ الْقَصِيدَةَ
الْألْفُ ( فَرْعِيَّةَ ) لِلْمُثَنَّى عَادَ الصَّدِيقَانِ مِن الرِّحْلَةِ
الواو ( فَرْعِيَّةَ ) لِجَمَعَ الْمُذَكَّرُ السَّالِمُ نامَ اللَّاعِبُونَ مُبَكِّرًا
الواو ( فَرْعِيَّةَ ) لِلْأَسْمَاءَ الْخُمُسَةَ قَابَلَ أَبُوكَ الْمُعَلِّمَيْنِ
أَنْوَاعُ الْفَاعِلِ

لَا يَقْتَصِرُ الْفَاعِلُ عَلَى كَوْنِهِ اِسْمًا ظَاهِرًا فَقَط ، بَل لَه ثَلَاثَةِ أَشْكَالٍ

  • • اِسْمُ ظَاهِرُ : كَلِمَةُ وَاضِحَةُ مَكْتُوبَةُ . ( صَاحَ الدِّيكُ ).
  • • ضَمِيرُ بَارِزُ مُتَّصِلُ : حَرْفُ ( ضَمِيرَ ) يَتَّصِلُ بِآخِرِ الْفِعْلِ وَيُعْرِبُ فَاعِلًا. مِثْل تَاءِ الْفَاعِلِ : ( فَهِمْتُ ، فَهِمْتَ ، فَهِمْتِ ). التَّاءَ ضَمِيرُ مُتَّصِلُ مَبْنِيُّ فِي مَحَلِّ رَفْعِ فَاعِلِ.
  • • ضَمِيرُ مُسْتَتِرُ ( مَخْفِيَّ ) : الضَّمِيرَ غَيْرَ مَكْتُوبٍ ، لَكِنّ الْعَقْلِ يُدْرِكُهُ ، ولَا يَجُوزُ خِلْوُ الْفِعْلِ مِن الْفَاعِلِ. إِذَا قُلْنَا لِلْمُخَاطِبِ : ( اِقْرَأْ الْقِصَّةَ ). الْفَاعِلَ هُنَا ضَمِيرُ مُسْتَتِرُ تَقْديرِهِ ( أَنْت ). وَإِذَا قُلْنَا : ( الْمَرِيضُ شُرْبَ الدَّوَاءِ ). " الْمَرِيضَ " هُنَا مُبْتَدَأٍ أَيْن فَاعِلُ الْفِعْلِ ( شُرْبَ ) ؟ الْفَاعِلَ ضَمِيرُ مُسْتَتِرُ تَقْديرِهِ ( هُو ) يَعُودُ عَلَى الْمَرِيضِ.
⚠️ مُلَاحِظَةً مُهِمَّةً: الْفِعْلُ فِي أَوَّل الْجَمَلَةِ يُكَوِّنُ دَائِمًا بِصِيغَةِ الْإِفْرَادِ ، فلَا نُقُولِ " حَفِظُوا الطُّلَاَّبُ " بَل " حَفِظَ الطُّلَاَّبُ ".
اختبر نفسك

١ اِسْتَخْرَجَ الْفَاعِلُ مِن الْجَمَلِ الْآتِيَةِ ، وَاُذْكُرْ عُلَّامَةَ إِعْرَابِهِ : ( مَاتَ الرَّجُلُ فِي الْحَادِثِ ، نامَ اللَّاعِبُونَ مُبَكِّرًا ، شَرِبَ الدَّوَاءَ الْمَرِيضُ ، قَابِلٌ أَبُوكَ الْمُعَلِّمَيْنِ )

٢ حَدَّدَ نَوْعُ الْفَاعِلِ ( اِسْمَ ظَاهِرَ ، أَم ضَمِيرُ مُتَّصِلُ ، أَم ضَمِيرُ مُسْتَتِرُ ) فِي الْآتِي : ( صَاحَ الدِّيكُ فَجَرَّا ، فَهِمْتُ الدَّرْسَ جَيِّدًا ، أَنْجِزْ الْعَمَلَ فِي وَقْتهُ )

٣ أَعْرِبْ الْفَاعِلَ فِي الْجُمْلَةِ الْآتِيَةِ إِعْرَابًا تَامًّا: (تَأَلَّقَتْ الطَّالِبَاتُ فِي الْمُسَابَقَةِ)
